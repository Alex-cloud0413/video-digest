YouTube Digest

Bring your own API keys

Keys stay in this Chrome profile and are sent only to the providers you configure. This open-source extension has no developer server or analytics.

Transcript provider

Used to fetch timestamped YouTube subtitles. Get a Supadata key.

AI provider

DeepSeek uses https://api.deepseek.com and deepseek-v4-flash.

When you use AI features, the selected provider receives the video transcript and relevant video context. Review that provider’s terms and pricing before saving.

Local data

Digests, translations, and notes are stored only in this Chrome profile. You can remove them at any time.

Read PRIVACY.md in the repository for the complete data-flow description.
